# Coordinated agentic-development baseline

- Optimize for one shared product outcome; team-local completion is not success when integration regresses.
- Treat ownership as stewardship and review responsibility, never exclusive edit permission.
- Use capability teams for durable expertise and temporary mission crews for cross-functional delivery.
- Give each mission one decision owner, explicit interaction modes, non-overlapping delegated scopes and shared acceptance criteria.
- Split ambiguous decision classes until one owner is deterministic; name a default owner for inseparable mixed cases.
- Put universal invariants in root instructions, mutable status in a status register, path-local constraints in nested instructions and repeatable procedures in skills.
- Express important seams as public interfaces, versioned contracts or reviewable artifacts with named stewards and consumers.
- Keep permissions task-scoped and least-privilege. Agents cannot simulate legal, destructive-action, security-sensitive or external-system approval.
- Make machine review routing canonical: document its path-glob grammar, declare conditional triggers and exercise every route with a concrete fixture.
- Validate rule structure, agent permissions and routing mechanically, then validate behavior with independent golden/adversarial scenarios.
- Convert recurring failures into a clearer contract, tool, fixture or check before adding another permanent instruction.
